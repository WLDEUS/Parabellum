# Revue de production — novembre 2026

Revue menée contre la grille PAB-1 (docs/BENCHMARK.md). Outils : `cargo clippy -D warnings`,
`cargo deny` (RustSec), `pip-audit` (verrous Python), `zizmor` (workflows GitHub), `shellcheck`
(scripts, installeur), fuzzing déterministe maison (sans dépendance ajoutée), lecture du code des zones
à risque (IPC root, mise à jour, quarantaine, parseurs, coffres), observation sur le Mac (Moniteur
d'activité, Finder).

## 2. Vérifié sans écart

- **IPC** : identité du pair par jeton d'audit pris à la connexion (`proc_pidpath_audittoken` échoue si
  le processus a fait `exec`), socket `root:admin 0660`, commandes sensibles réservées à l'app / la CLI
  installées de l'utilisateur de la console, droits d'administration via Authorization Services.
- **Mises à jour** : minisign vérifié **avant** décompression, décompression stricte, rétrogradation
  refusée, retour arrière ; gel des mises à jour visible (âge de la base > 48 h dans le rapport du jour).
- **Quarantaine** : chaîne `openat(O_NOFOLLOW)`, refus des liens symboliques, restauration revalidée.
- **Outils externes** (hdiutil, pkgutil, clamscan…) lancés avec privilèges abaissés.
- **Chaîne d'approvisionnement** : actions épinglées par SHA, verrous Python hachés (`--require-hashes`,
  `pip-audit` : 0 vulnérabilité), `cargo deny` vert après R4, `shellcheck` sans avertissement.
- **Runtime renforcé** : seule exception `allow-unsigned-executable-memory` (JIT wasmtime de YARA-X).
