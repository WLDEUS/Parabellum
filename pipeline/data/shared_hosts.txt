# Shared platforms: a malicious URL hosted there must NOT turn into a DNS block of the platform.
# Applied to every list (URLhaus/ThreatFox mostly). Syntax:
#   example.com        never block this host, nor any of its parents (blocking google.com would
#                      block drive.google.com); user-specific subdomains (evil.github.io) stay blockable
#   *.example.com      additionally never block any host under it (shared infrastructure whose
#                      per-file hostnames would only produce useless or harmful entries)
