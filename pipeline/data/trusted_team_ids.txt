# Trusted Apple Developer Team IDs -> allow/team_ids.txt in the bundle.
# A binary signed with one of these Team IDs AND notarized (verified by the engine with codesign /
# spctl) gets a lower suspicion score and is never flagged by ML alone. Signature-based detections
# (hash DB, ClamAV, YARA high/critical) still apply: a stolen/abused certificate is not a free pass.
#
# Apple's own software is identified by the Apple anchor ("platform binary" / `anchor apple`), not by a
# Team ID, and is handled separately by the engine.
#
# Every ID below was verified on 2026-10-25 by reading the code signature of an official artefact
# (CodeDirectory teamID of a Developer ID-signed Mach-O, or the "Developer ID Installer" certificate
# OU of a flat .pkg) downloaded from the vendor's official GitHub releases:
#
